CrewVoice shoot script

Six segments, two and a half minutes. Amber lines are spoken into the microphone at the agent and must be audible in the take; plain lines are voice-over laid on afterwards.

2:30 target 1280×720 screen capture English narration 3 takes of the live pass
0:00–0:20

The argument

On screen: a spreadsheet timesheet, cursor tracking along one row; a phone thread with the foreman open beside it.

Voice-overEnd of the month on a construction site. Payroll has a number for Jose. Jose says the number is wrong. The only record of what was actually said is a foreman's memory and a smudged notebook. Somebody is going to lose this argument without any evidence.

0:20–0:35

What it is

On screen: CrewVoice opens, sheet empty, cursor resting on Start talking.

Voice-overCrewVoice takes the foreman's spoken end-of-day report and turns it into a timesheet that can be audited line by line. It runs on AssemblyAI's Voice Agent API — speech in, speech out, tool calls in the middle.

0:35–1:05

The clean pass

Do: press Start talking, then speak. Let the agent's own voice answer — don't talk over it.

Say to the agentJose worked nine hours today.

Agent reads back “José Ramírez, nine hours — is that right?” A yellow pending row appears. Hold the cursor on it so the word is readable.

Say to the agentYes.

Voice-overNine hours is on the sheet — but only because I said yes out loud. Until then it sat in pending, outside payroll.

1:05–1:35

Three refusals

Do: run all three without stopping to explain — the voice-over goes on top. This is the segment the submission is judged on.

Say to the agentMiguel worked twenty hours.

Say to the agentBobby worked eight hours.

Say to the agentLuis trabajó ocho horas. — then — Sí.

Voice-overTwenty hours in a day is a mishearing, not a shift. A name that is not on the crew list is a question, never a guess. And the crew switches to Spanish mid-shift, so the agent does too. None of these three rules live in the prompt — they live in the tools, which is why the model cannot talk its way past them.

1:35–2:05

The evidence

On screen: the HEARD AS column — row José Ramírez carrying Jose. Hover it so the original sentence surfaces, then press Export CSV and open the file.

Voice-overSpeech recognition wrote “Jose”. Payroll has “José”, with an accent. Same man — the roster match folds both to the same key, and the sheet keeps what was actually heard.

Voice-overThe export carries two extra columns: what recognition heard, and the sentence it came from. When Jose disputes his hours, the record settles it instead of whoever remembers harder. Rows nobody confirmed are simply not in this file.

2:05–2:30

Close

On screen: the architecture diagram from the README, then the KHLab mark.

Voice-overVoice Agent API for the conversation, a tool layer that refuses to write anything it was not told to confirm. Built in three weeks, running on a free instance, ready for a crew of six or six hundred. CrewVoice — the foreman talks, payroll gets numbers it can prove.

Before you roll

Ticks are remembered on this device, so you can close the page between takes.

Don't say

  • “We use cutting-edge AI models.” The judges build those models.
  • Roadmap promises. Scoring covers what is on screen, nothing that is coming later.
  • Apologies for plain design. A timesheet should look like a timesheet.
  • Invented statistics. No “$X billion lost to payroll errors” — an unverifiable number is the fastest way to lose a technical audience.
